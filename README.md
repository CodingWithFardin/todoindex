# todoindex

Scan a repo for TODO/FIXME markers and emit a markdown index.

```
python todoindex.py .
```

## notes

Scan a repo for TODO/FIXME markers and emit a markdown index. Standard library only.

Runs on 3.11 and newer.

Start at `todoindex.py`. Each function fits on a screen.

Tests: `tests/test_todoindex.py`. A change that breaks one is usually the wrong change.
